# Zvukbook: запуск и продолжение озвучки

Это пользовательская справка по локальной мастерской Zvukbook. Первичная подготовка новой копии, Windows/Linux-запуск и сборка описаны в [README](../README.md).

## Запуск

Если Linux-окружение, модель и системные инструменты уже подготовлены, из корня проекта в терминале графической сессии, без sudo:

```bash
bash scripts/start-local.sh
```

Страница — **[http://127.0.0.1:8767/](http://127.0.0.1:8767/)**. Остановить сервер — **Ctrl+C**. После обновления кода останови его, запусти снова и обнови страницу (при необходимости Ctrl+F5). Для другого порта: `bash scripts/start-local.sh --port 8768`.

Теперь действует **один список глав и один текущий MP3 для каждой главы**. При первом запуске обновлённого сервера старые записи переносятся из аудиоверсий в папку `mp3/`: подходящие к текущему тексту главы сохраняют готовность, отредактированная глава требует обновления. Файлы сначала копируются с проверкой SHA, затем прежние папки аудиоверсий удаляются. Сам перенос ещё не выполнялся агентом.

Если перенос прервётся, повторный запуск использует уже проверенные копии. Во время перехода нужны место для копий и резерв 5 GiB. Старые ожидавшие задания не запускаются автоматически: продолжи через выделение неозвученных. Известные версии SQLite-хранилища — 1 и 2, текущая — 2.

## Продолжить после ошибки, например на главе 85

1. У главы **85** нажми **«Проверить текст»**, исправь проблемное место и сохрани. Готовность остальных глав с неизменённым текстом сохраняется.
2. Нажми **«Выделить неозвученные»**. Отметятся отсутствующие, незавершённые и отредактированные главы; готовые не выберутся. При открытии книги такое выделение включено по умолчанию.
3. Нажми **«Озвучить выделенные»**. Результат появится в тех же карточках: состояние, длительность, **«Слушать»**, **«MP3»**, **«Переозвучить»**.

Запоминать последний номер или искать старую аудиоверсию не требуется. Выполненные главы снимаются с автоматического выделения по мере готовности. Ручное изменение галочек переключает выбор в ручной режим; кнопка «Выделить неозвученные» возвращает автоматический выбор оставшихся.

**Каждая явно выбранная глава озвучивается заново**, даже если её текст и голос не менялись. Готовый новый файл атомарно заменяет прежний `0085.mp3`; отдельная история MP3 не создаётся. Если генерация не удалась, последняя запись сохраняется в той же карточке, но глава отмечается как требующая озвучки. Ошибка/отмена не удаляет готовые файлы других глав.

**«Выделить все» → «Озвучить выделенные»** или **«Озвучить всю книгу заново»** заменяет аудио всей книги. Для продолжения после сбоя используй именно неозвученные. Параметры голоса показаны рядом с готовой главой; при желании их можно менять для выбранных глав.

## Загрузить книгу

В верхней панели есть переключатель **«Тёмная тема»**. До первого ручного
переключения используется тема системы, затем выбор сохраняется локально
в браузере/Windows-окне и применяется при следующем открытии. Тема охватывает
галерею, главы, редакторы, предупреждения и плеер. В Windows меняется также
оформление заголовка окна. Если браузер запретил localStorage, переключение
работает в текущем окне, но не сохраняется после закрытия.

Для новых книг папка готового аудио теперь имеет понятное имя:
`library/mp3/Название — Автор [короткий ID]/`. Название берётся после успешного
извлечения текста; недопустимые для Windows знаки заменяются пробелами.
ID различает одноимённые книги. Папка закрепляется за книгой и не меняется
при последующих правках текста, названия или автора. «Открыть папку MP3»
открывает её напрямую. Перенос прежних тестовых аудиопапок не выполняется.

В эту же папку при наличии встроенной обложки EPUB/FB2/FB2.zip сохраняется **`cover.jpg`**. Для EPUB при отсутствии явно указанной обложки приложение пробует изображение с первой страницы. Для PDF/DJVU оно использует первую страницу: она может оказаться титульным листом. JPEG имеет размер до 1200×1600,
сохраняет пропорции; прозрачность заменяется белым фоном. Обложка входит и в
ZIP с MP3, а её SHA записан в дополнительном поле `cover` manifest v2.
Если обложки нет, в приложении показывается логотип, но отдельный `cover.jpg`
с логотипом не создаётся и в ZIP не добавляется. Ранее извлечённые изображения
PDF/DjVu показываются в приложении и попадают в ZIP. При ошибке обработки картинки появляется
предупреждение, импорт текста продолжается. Векторный SVG без вложенной растровой картинки
не преобразуется. Сетевые картинки не загружаются, новых зависимостей нет.
Это внешний `cover.jpg` для поддерживающих его плееров; в ID3 каждого MP3
картинка не встраивается. Извлечение обложки происходит при новом импорте,
не при обычном повторе озвучки уже подготовленного текста.

Кнопка **«Название, автор и обложка»** открывает окно с текущей картинкой.
Выбери свою JPG/PNG/WebP (до 16 MiB и 20 млн пикселей), посмотри предпросмотр
и нажми **«Сохранить»**. «Отменить выбор картинки» возвращает текущую обложку,
пока изменения не сохранены. Подготовка новой картинки отображается в карточке
задачи; после завершения появляется сообщение и обновляется миниатюра книги.
Обложка нормализуется в cover.jpg рядом с MP3 и входит в ZIP. Повреждённая
картинка не заменяет прежнюю, а готовность глав не сбрасывается.
Своя обложка сохраняется после повторного извлечения текста из книги.
Во время активной задачи этой книги изменение метаданных/обложки недоступно.

Слева: файл → **«Загрузить и подготовить текст»**. Поддержаны FB2/FB2.zip, EPUB, TXT, DOCX/DOC, PDF, DJVU/DJV; до 100 MiB. Проверь извлечённый текст, создай короткий образец, затем озвучь нужные главы. Всё остаётся на этой машине; текст не уходит в облако.

DJVU с пригодным русским текстовым слоем использует его, иначе выполняются постраничный `ddjvu` и Tesseract rus. В настройках можно принудительно включить OCR всех страниц PDF/DJVU. Составной DJVU с внешними компонентами требует предварительно собранного однофайлового документа.

Галерея **«Все книги»** содержит поиск/фильтры и действия: открыть, изменить текст, название/автора, выбрать всю книгу для переозвучки, удалить. Изменение названия/автора книги не сбрасывает готовность остальных глав.

## Очистка текста

### Произношение, замены и ударения

В карточке книги нажми **«Произношение, замены и ударения»**. Правила
сохраняются для этой книги, а при применении изменяют подготовленный текст
выбранных глав. Загруженный исходный файл не переписывается.

1. **Замены:** укажи «Что заменить» → «На что», например `м2` → `метров
   квадратных`, и нажми «Добавить замену». Поиск идёт по целым словам и фразам,
   без учёта регистра; замены не запускают друг друга по цепочке. Пустой
   результат удаляет совпадение из текста.
2. **Ударения:** введи `злодЕя` (также принимаются `злоде́я` и `злод+ея`) и
   добавь правило. Для каждой словоформы, например `злодЕй`, нужна своя строка.
   В сохранённом тексте ударная гласная помечается знаком ударения, а в
   предпросмотре речи — знаком `+` перед ней.
3. Выбери главы в разделе **«Главы для применения правил»**: по умолчанию
   отмечены все. Нажми **«Применить правила к выбранным главам»**. Текущие ручные
   правки открытой главы тоже сохраняются. Показаны число замен, ударений и глав
   с изменившимся чтением. При более чем 20 000 изменений за один раз выбери
   меньше глав и повтори: операция целиком отменяется.
4. Нажми **«Посмотреть изменения»** и выбери нужную запись: откроется глава с
   выделенным местом. Проверь падеж, при необходимости исправь и нажми
   **«Сохранить правку главы»** — эта кнопка не применяет все правила повторно.
   Список относится к последнему применению и доступен до закрытия окна. Если
   участок потом изменён вручную, позиция в списке может стать приблизительной.
5. Для нового аудио нажми **«Выделить неозвученные» → «Озвучить выделенные»**.
   Неизменённые готовые главы сохраняются.

Изменение или удаление правила не отменяет уже записанные замены. Для возврата
текста можно повторно извлечь книгу из оригинала, но это заменит все ручные
правки; сохранённые правила затем нужно применить заново. У книг со старыми
правилами прежнее автоматическое чтение сохраняется для невыбранных глав, а
выбранные переходят на записанные в текст изменения. Для активной книги правка
недоступна. Лимиты: по 300 замен/ударений, поиск до 160 знаков, результат до
500, глава до 1 млн знаков, подготовленная речь до 2 млн знаков.

Автоподготовка раскрывает `м2`/`м²`/`м^2`/`кв. м`, кубические единицы, длину,
массу, объём, время, скорость (`км/ч`, `м/с`), часть физических величин/валют,
`т. е.`, `т. к.`, `и т. д.`, `и т. п.`, `н. э.`, `см.`, `рис.`, `табл.`, `стр.`.
Например: `2 м²` → «два квадратных метра», `5 м2` → «пять квадратных метров»,
`2 мин` → «две минуты». Одиночное строчное `м.` — «метры», инициалы `М. Горький`
сохраняются. Для `г.` (год/город/грамм) глобальное угадывание не включено.
Согласование по числу/дроби есть, полное падежное управление и все книжные
сокращения не реализованы — спорные места исправляй собственными правилами.
Обновлённые автоэвристики действуют при следующей озвучке. Старые готовые MP3
не пересоздаются и не помечаются все устаревшими только из-за обновления
нормализатора: выбери нужную главу вручную и нажми «Переозвучить», либо запусти
книгу заново. Применение ручных правил пересчитывает готовность затронутых глав.

Источники решений: [сокращения в «Письмовнике» Грамоты](https://gramota.ru/biblioteka/spravochniki/pismovnik/kak-pravilno-sokrashchat-slova),
[графические сокращения](https://gramota.ru/biblioteka/spravochniki/pravila-russkoy-orfografii-i-punktuatsii/graficheskie-sokrashcheniya),
[примеры ударений Silero](https://github.com/snakers4/silero-models/wiki/SSML).
Знак `+` и приоритет ручного ударения дополнительно просмотрены в Python-коде
поставляемой модели, без её загрузки/исполнения. Качество нового чтения
остаётся ручной слуховой проверкой владельца.

Кнопка **«Убрать примечания и звёздочки без OCR»** работает с текущим текстом, сохраняя твои исправления. Указатель `слово*,` превращается в `слово,`, сноска `* Пояснение… — Прим. ред.` удаляется целиком. Есть поддержка `Прим. науч. ред.`, `Прим. пер.` и нескольких комментариев подряд. Исключённый текст сохранён в отчёте. Главы, текст которых изменился, попадут в неозвученные; остальные готовые файлы сохраняются.

В разделе **«Извлечение текста и очистка PDF/DJVU»** доступны колонтитулы, оглавление/номера/служебные строки, списки литературы, редакторские примечания, OCR и кодировка TXT. Видны причины/счётчики исключений, первые 100 записей и скачивание полного JSON-отчёта. Это эвристики: просмотри результат, особенно PDF-колонки и формулы.

**«Извлечь текст заново»** берёт оригинал и заменяет текущие ручные правки. Если изменился порядок/состав глав, части аудио может понадобиться новая озвучка; неозвученные определяются по текущему тексту и номеру главы. Для возврата ошибочно удалённых примечаний выключи соответствующую опцию и повтори импорт. Для полного отключения очистки PDF/DJVU выключи основную очистку и колонтитулы.

Звёздочки также убираются на границе Silero до деления на короткие фрагменты. Для известных ошибок разметки разрешён один повтор с изменённой упрощённой пунктуацией. Неустранимая ошибка содержит главу и номер фрагмента; значимый текст не пропускается молча. Ошибки CUDA/OOM автоматически не повторяются.

## Папка MP3, скачивание и удаление

**«Открыть папку MP3»** открывает файловый менеджер на этом компьютере. Путь также показан на странице, его можно скопировать. В папке лежат `0001.mp3`, `0002.mp3`…; `0000.mp3` — последний образец голоса, если создавался.

Отдельную главу можно скачать кнопкой **«MP3»**. ZIP остаётся дополнительной возможностью: экспортирует главы с актуальным готовым аудио, с порядком, длительностями, настройками и SHA в `manifest.json` (`projectpro-audiobook-v2`). В ZIP не входят неготовые/устаревшие главы и образец. Пока у книги активная задача, ZIP недоступен, а папку открывать можно.

**«Удалить»** после подтверждения удаляет весь каталог книги (оригинал, версии текста, все MP3), каталоги её задач и записи SQLite. При ошибке удаления приложение сообщит о ней и сохранит запись для повторного удаления. Если обработка ещё идёт, сначала нажми «Остановить» и дождись остановки.

```text
.local-data/books-renderer/
  .venv/                            Python/CUDA
  models/silero-v5_6_ru/             модель, LICENSE, README, manifest
  library/
    library.sqlite3                 книги, очередь, состояние каждой главы
    books/<book_id>/
      source.<формат>                оригинал
      canonical/<sha256>.json        версии текста и отчёт очистки
      mp3/0001.mp3                  единственный текущий MP3 первой главы
    jobs/<job_id>/worker.log         журнал задачи
```

Каталог исключён из Git. Резервная копия — `library/` целиком после остановки сервера. Загрузка готового аудио на сервер и история Android — последующий отдельный этап этого проекта; место размещения ещё не выбрано.

## Ресурсы и сообщения об ошибках

Linux: до трёх CPU-эквивалентов на группу, RAM high 6 GiB / hard 8 GiB / без swap, до 128 задач/потоков, одна обработка. PyTorch allocator до 60% VRAM; это не квота загрузки всего GPU. Резервы: VRAM 2 GiB перед стартом / 1 GiB между фрагментами, RAM 8 GiB перед задачей / 6 GiB во время, диск 5 GiB. Windows использует другой адаптивный профиль: [справка](windows-build.md). Linux-пакеты — [requirements.lock](../requirements.lock).

Если запуск не удался, пришли ошибку терминала. Если упала задача — сообщение и её `worker.log`, без личного текста книги. Ошибки user systemd/bubblewrap разбираем по конкретному сообщению, запуск без защиты не включается. Открытие папки требует обычной графической сессии; если файловый менеджер недоступен, страница покажет путь.

Текущие изменения просмотрены по исходникам. При выделении проекта исправлены пути перенесённого Python-окружения; зависимости повторно не устанавливались. **Автоматические тесты, миграция схемы личной библиотеки, браузерные/smoke-проверки, запуск сервера после переноса, открытие файлового менеджера и синтез агентом не запускались** по выбранному владельцем ручному порядку приёмки.
