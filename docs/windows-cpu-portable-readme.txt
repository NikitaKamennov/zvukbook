Звуккниг CPU — облегчённая офлайн-сборка для процессора

1. Установи Zvukbook-CPU-Setup.exe либо распакуй ВСЮ папку Zvukbook-CPU
   из Zvukbook-CPU-Portable.zip на локальный NTFS-диск в свою доступную папку.
   Не запускай программу внутри ZIP и не переноси один EXE отдельно от папок.
2. Открой Zvukbook.exe (после установки — ярлык «Звуккниг CPU»).
3. В первом окне подтверди работу на процессоре.
4. Загрузи книгу, проверь текст, выбери голос и озвучь главы.

Это версия без CUDA: ускорение NVIDIA недоступно даже на ПК с видеокартой.
Все голоса Silero, Python/PyTorch CPU, русский OCR, FFmpeg, DjVuLibre,
WebView2 и библиотеки Microsoft Visual C++ входят в комплект.
Окружение и драйвер NVIDIA устанавливать не нужно; импорт и озвучка без сети.
Для NVIDIA используй полную сборку с именем Zvukbook-Setup.exe.

Ориентир: Windows 10 (19041+)/11 x64, 4 GiB общей RAM и выше,
достаточный свободный бюджет сверх резерва Windows. Это проектный ориентир,
приёмка на слабом ПК остаётся ручной. CPU ограничен 25%, одна задача за раз.
Озвучка на слабом ноутбуке может идти медленнее самой записи.
Оставь 5 GiB свободного места сверх приложения и места под книги/MP3.

Форматы: TXT, FB2/FB2.zip, EPUB, DOCX, PDF, DJVU/DJV. DOC не поддерживается.
Книги и MP3: %LOCALAPPDATA%\Zvukbook\, отдельно от приложения.
Полная и CPU-версии используют одну библиотеку; запускай одну из них за раз.
Если раньше был выбран GPU, подтверди CPU явно. Автоматической переозвучки нет.

CPU-установщик ставит программу отдельно в %LOCALAPPDATA%\Programs\Zvukbook-CPU.
Он не удаляет полную сборку и её CUDA. Удаление любой версии сохраняет библиотеку.
Portable распаковывай в отдельную папку, поверх полной сборки не накладывай.
