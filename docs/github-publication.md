# Публикация исходников Zvukbook на GitHub

Публикуется исходный проект. Пользователь скачивает его, подготавливает модель
и собирает нужную Windows-комплектацию у себя. **Установщики и portable-архивы
в репозиторий и GitHub Releases не загружаем.**

## Состав репозитория

- README, MIT LICENSE и THIRD-PARTY.md.
- `book_renderer/`, `desktop/`, входной `zvukbook.py`.
- Сборочные скрипты, `scripts/prepare-model.py`, конфиги и manifest модели.
- Все lock-файлы Python, `desktop/go.mod` и `go.sum`.
- Сохранённая лицензия Silero в `licenses/`, без весов модели.
- Пользовательские инструкции и синтетические тесты/голосовые тексты.

`.gitignore` оставляет локально `.local-data/`, книги/аудио/SQLite, модели,
runtime, пакеты, установщики/архивы, кэши, логи, `.env`/ключи, редакторские
настройки и внутренние планы/обследования. Они не удаляются, а исключаются
из обычного `git add`. Не обходи эти правила через `git add -f`.

`.gitattributes` сохраняет LF для исходников/Linux-скрипта, CRLF для Windows
launcher-файлов. Сохранённая лицензия модели передаётся без преобразования
байтов: её SHA проверяется при подготовке.

## Первый публичный репозиторий

На момент подготовки `origin` не был настроен, исходники не были добавлены
в индекс. Агент коммиты и push в этом проходе не выполнял.

1. Создай на GitHub пустой public-репозиторий `zvukbook`. README/LICENSE/.gitignore
   уже есть локально; при создании репозитория их повторно не добавляй.
2. Из корня **Zvukbook**, не ProjectPro, выполни:

   ```bash
   git status --short --untracked-files=all
   git add .
   git diff --cached --stat
   git diff --cached --name-only
   ```

   В индексе должны быть только исходники, конфиги, lock и документация.
   `.gitignore` не убирает уже индексированные файлы автоматически: если раньше
   добавлял их принудительно, сначала убери из индекса, сохранив локальную копию.

3. После просмотра создай коммит и подключи свой репозиторий.
   В URL замени `YOUR_ACCOUNT` на аккаунт/организацию:

   ```bash
   git commit -m "Prepare Zvukbook for public source release"
   git branch -M main
   git remote add origin https://github.com/YOUR_ACCOUNT/zvukbook.git
   git push -u origin main
   ```

   Если позже уже настроил `origin`, повторный `remote add` не нужен.
   Авторизацию выполняй через Git/менеджер учётных данных; токены не вставляй
   в README и URL команд.

4. На главной странице будет показан корневой README с Windows/Linux-запуском,
   CPU/full-сборкой, установщиком/portable и пользовательской инструкцией.

## Новая машина и выпуск

После клонирования не нужна библиотека владельца или его `.local-data`.
`scripts/prepare-model.py` скачивает закреплённые веса из официального источника,
Windows-сборщик готовит зависимости по lock/manifest. Linux-окружение создаётся
по README. Интернет нужен для первоначальной подготовки; при озвучке модель
скрытно не скачивается.

Для нового локального выпуска задай версию в `config/windows-release.json`
и выполни [команды сборки portable](../README.md#windows-сборка-portable).
Полный архив создаётся в `.local-data/windows-x64/portable/`, CPU — в
`portable-cpu/`. Файлы, SHA256SUMS и manifest остаются локально.

Сборщик не запускает приложение/установщик и не заменяет ручную приёмку.
Публикация бинарников не является частью этого GitHub-проекта. MIT приложения
и отдельные условия модели/компонентов перечислены в
[THIRD-PARTY.md](../THIRD-PARTY.md).
