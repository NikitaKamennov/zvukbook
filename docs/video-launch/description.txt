Твои книги обретают голос: запускаем нейросеть для озвучки локально на вашем ПК. Текст не отправляется в облачный сервис, а результат сохраняется в обычные MP3.

В этом видео показываю «Звук книг»: скачиваю CPU portable-архив, распаковываю его на Windows, запускаю приложение, добавляю книгу, проверяю текст, настраиваю замены и ударения. Затем озвучиваю первые главы и даю послушать результат.

Что умеет приложение:
• Локальная нейросетевая озвучка на русском языке — Silero.
• FB2/FB2.zip, EPUB, TXT, DOCX, PDF и DjVu.
• Русский OCR для сканов без пригодного текстового слоя.
• Редактор глав, замены, ударения и просмотр внесённых изменений.
• Выбор голоса, скорости и высоты.
• MP3 по главам и продолжение после остановки без переозвучки готовых глав.

Для первого знакомства выбирай CPU-версию: Python, CPU PyTorch, модель и OCR уже в комплекте. Распакуй ВСЮ папку и открой Zvukbook.exe. Для совместимой NVIDIA есть полная сборка. Пошаговые инструкции — в README на GitHub и разделе «Помощь» внутри приложения.

После скачивания комплект обрабатывает книги локально: текст не отправляется во внешний сервис озвучки или распознавания. CPU-версии не нужна отдельная NVIDIA, но время генерации зависит от компьютера. На слабом процессоре озвучка может идти медленнее прослушивания; ошибки OCR и произношения иногда нужно поправить вручную. Целевая ОС — Windows 10 19041+ / Windows 11 x64. Для Linux есть отдельный запуск из исходников по README.

Попробовал? Напиши в комментариях свой процессор, объём RAM, формат книги и что получилось. Особенно полезны конкретные примеры неверного чтения и ошибок — будем дорабатывать проект.
