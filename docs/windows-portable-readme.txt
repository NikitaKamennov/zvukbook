Звуккниг — локальная подготовка русских аудиокниг

1. Распакуй ВСЮ папку Zvukbook из ZIP на локальный NTFS-диск, например
   в свою папку «Документы». Не запускай приложение прямо внутри архива.
2. Открой Zvukbook.exe.
3. Выбери устройство озвучки: процессор (включая слабые ноутбуки)
   или доступную совместимую NVIDIA. Сохрани выбор.
4. Загрузи книгу, проверь извлечённый текст, выбери голос и озвучь главы.

Python, PyTorch, Silero, OCR с русским языком, FFmpeg, DjVuLibre,
WebView2 и библиотеки Microsoft Visual C++ входят в комплект.
Устанавливать окружение, выполнять команды и подключать интернет не нужно.

Процессор работает без NVIDIA. Для видеокарты нужен совместимый драйвер;
при его отсутствии выбери процессор. При ошибке GPU автоматической смены
устройства и повторного запуска нет. Устройство меняется кнопкой вверху окна.

Ориентир CPU: Windows 10 (19041+)/11 x64, 4 GiB RAM и выше,
хотя бы 1 GiB доступного бюджета worker сверх резерва для Windows.
На компьютере с 4 GiB может потребоваться закрыть браузер и другие программы.
Это проектный ориентир, а не результат приёмки на слабом ноутбуке.
Ниже физического минимума памяти задача безопасно откажет в запуске.
На слабом процессоре рендер может идти медленнее самой записи.
Оставь 5 GiB свободного места сверх комплекта и места под книги/MP3.

Форматы: TXT, FB2/FB2.zip, EPUB, DOCX, PDF, DJVU/DJV. DOC пока не поддерживается.
Текст и аудио остаются на этом компьютере; OCR и синтез работают локально.

Книги, настройки и MP3: %LOCALAPPDATA%\Zvukbook\
«Открыть папку MP3» показывает готовые главы. Пересборка/обновление программы
и удаление через установщик не удаляют библиотеку.

Одна тяжёлая задача, CPU до 25%, фиксированный на задачу бюджет памяти.
При нехватке памяти/диска работа останавливается, готовые главы сохраняются.
Долгую книгу после остановки можно продолжить через «Выделить неозвученные».

Для обычной установки можно использовать Zvukbook-Setup.exe вместо ZIP.
Права администратора и отдельная установка Python/OCR/PyTorch не нужны.
Лицензии компонентов — THIRD-PARTY.md и файлы LICENSE рядом с компонентами.

Этот выпуск требует ручной приёмки на компьютере получателя.
