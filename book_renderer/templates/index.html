Подготовка текста к озвучке

    

    
Добавь правила, выбери главы и примени их к тексту. По умолчанию выбраны все главы. Изменения записываются в подготовленный текст книги; исходный загруженный файл остаётся прежним. Изменённые главы потребуется озвучить заново.

    
Для этой книги уже были сохранены старые правила, действовавшие при озвучке. После применения выбранные главы используют исправленный текст; для остальных прежние правила пока сохраняются.

    

      

        
Ручные замены 0

        
Целые слова и фразы, без учёта регистра. Например: СССР → эс эс эс эр. Пустое «На что» удаляет совпадение из текста выбранных глав.

        

          
          
          

        

        

      

      

        
Ударения 0

        
Выдели одну ударную гласную заглавной: злодЕй. Можно написать злоде́й или злод+ей. Каждая словоформа задаётся отдельно: злодЕй, злодЕя.

        

          
          

        

        

      

    

    

      
Быстрое редактирование и предпросмотр

      
      

        
        
      

      
Справа показан будущий текст речи с правилами, без создания звука. В сохранённом тексте ударная гласная отмечена знаком ударения; справа ей соответствует + перед гласной. После применения проверь падежи и поправь их вручную.

      

      

    

    

      Главы для применения правил 
      
Отмечены все главы. Сними отметки там, где текст менять не нужно.

      

      

    

    

  
  
    
Изменения в тексте

    
Выбери изменение, чтобы перейти к этому месту в тексте главы. Исправь формулировку и нажми «Сохранить правку главы». Список относится к последнему применению и доступен до закрытия окна.
